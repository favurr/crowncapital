# Crown Capital

An interactive dashboard application for capital tracking and financial console management.

## 🚀 Features

- **Interactive Chart Component** - Real-time visual data mapping.
- **Console Page** - High-performance user interface built with React Suspense fallbacks.
- **Automated AI Reviews** - Integrated with CodeRabbit for precise pull request code analysis.

## 🛠️ Tech Stack

- **Frontend:** React / Next.js
- **Styling:** Tailwind CSS
- **State/Data:** Suspense for asynchronous data fetching

## 📦 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com
cd crowncapital
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
